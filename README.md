# Crypto Dash

Integrates with the CoinGecko API to retrieve cryptocurrency data. Dashboard displays coins by name, symbol, logo, and price market cap. Search, filter, and sort provide additional capabilities for viewing data. Coin details are represented numerically and graphically. Built using React, Router, and Chart.js.
